# Reference image visual checklist

Use these as concrete acceptance targets when comparing the actual app screenshots.

## Landing page reference (`reference/landing-page-reference.png`)
- [ ] dark, image-led first screen; nav visually integrates with hero
- [ ] left-aligned copy with readable contrast and natural line wraps
- [ ] right side has the primary photograph/envelope as a strong focal point
- [ ] one clear primary CTA plus a quieter secondary action
- [ ] hero first screen fits entirely without scrolling or cut-off
- [ ] below fold transitions deliberately to warm light surfaces
- [ ] subsequent section uses occasion diversity; not only weddings or floral stationery

## Multi-occasion reference (`reference/multi-occasion-modern-ui-board.png`, `reference/diverse-occasion-app-board.png`)
- [ ] wedding, birthday, graduation, housewarming, memorial, baby shower, holidays, corporate and other event examples visibly differ
- [ ] images communicate the actual occasion, not just a different color overlay
- [ ] mobile template browsing uses image-led cards and readable text
- [ ] editor, dashboard, gallery and public invitation have the same shared UI language
- [ ] any envelope opening is one optional experience, not a mandatory design for every template

## Workspace reference (`reference/workspace-reference.png`)
- [ ] dark navigation rail and light content canvas
- [ ] event overview has clear hierarchy and real data
- [ ] RSVP/guest management is scannable and table/list adapts to mobile
- [ ] template/editor area has a prominent real-time preview
- [ ] active navigation and primary actions are consistent across routes

## Cross-route invariants
- [ ] same font family/scale rules, button shapes, focus style, border and spacing rules
- [ ] event-specific colors apply to the guest invitation/preview only
- [ ] responsive crop checked individually at phone widths
- [ ] no overflowing content, clipped actions, fake metrics or dead controls

# Reference image index

Use these images as visual composition targets. They are not screenshots of the current running Kadi app. Match section order, hierarchy, image crop, spacing, type scale, page proportions and visual richness; don't merely imitate the colours.

- `landing-page-reference.png`: public long-form landing page direction; full viewport hero followed by varied occasion/template discovery and lower-page feature/story sections.
- `app-dashboard-reference.png`: workspace/dashboard direction and cross-screen visual consistency.
- `app-experience-reference.png`: additional application UI layout ideas.
- `occasion-diversity-reference.png`: diverse occasion visuals; not everything should inherit the Victorian/wax-seal treatment.
- `envelope-and-animations-reference.png`: dimensional stationery/envelope layers and motion states.
- `envelope-options-reference.png`: alternative envelope structures and styles.

All reference images are moodboards. Final source must use responsive, correctly licensed local/provider assets and data-driven components.
